Modern Warfare 2 for Android v0.1.9

Nothing to rebuild: the game code you built for v0.1.8 is used as it is, and your saves and settings are kept.

New
- Smoother at 120 Hz on an AYN Thor: sun shadows are off above 60 FPS, as in the other games (the heaviest views of Team Player 81-93 FPS before, 102-112 now). Settings, Graphics, Sun shadows, On brings them back.
- Updates are simpler from now on. The app checks the game code itself, so an update asks for a rebuild only when the code really changed, and then builds it by itself in the background.
- Multiplayer: an invitation goes only to the player you pick, and a private match on a server is no longer announced to everyone. When System Link finds nobody, the app asks whether both devices are on the same Wi-Fi.
- Fixed: the sound slowly fell behind the picture the longer you played.

Known issues
- Rarely, a shadow or a piece of the scene is missing for a single frame; being fixed.
- The first minutes on a fresh install stutter while shaders compile.
- Multiplayer over the internet needs a relay server; see the README.

Never share the game code you build: it contains the game. Unofficial fan project, not affiliated with Activision or Microsoft.
