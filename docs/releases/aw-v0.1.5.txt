Call of Duty: Advanced Warfare for Android v0.1.5

Nothing to rebuild: the game code you built for v0.1.4 is used as it is, and your saves and settings are kept.

New
- Fixed: the screens in Induction's drop pod could vanish for a frame at high frame rates. Textures the game redraws are now read when first used.
- Fixed: at a wide field of view a slide or boost dash left a blurred rectangle mid-screen; the blur now covers the whole picture. Checked in multiplayer, not yet in the campaign.
- Graphics presets (Automatic, Battery saver, Balanced, Best looking, Custom), an Advanced page and an FPS counter.
- Touch aiming: swipe on the right half of the screen to look, with sensitivity settings. Gyro aiming too, not yet tried on a device.
- Opt-in anonymous performance reports; the app won't ask, and nothing is collected, until the report server is up.
- You can uninstall the build tools once the game is built.
- Our Discord: https://yassin.app/discord

Known issues
- Automatic settings were measured on two devices only.
- Shaders are compiled again once after this update, so the first minutes stutter.
- Map packs are experimental.

Official downloads are only on GitHub Releases. Never share the game code you build: it contains the game. Unofficial fan project, not affiliated with Activision or Microsoft.
